# ClusterForge Branding

ClusterForge uses a restrained infrastructure/devtools identity built around two ideas:

- **cluster** — multiple connected compute nodes
- **forge** — a central engineered core where workloads are coordinated

## Primary logo

Use [`assets/clusterforge-logo.svg`](../assets/clusterforge-logo.svg) for documentation headers, project pages and presentations.

## Project mark

Use [`assets/clusterforge-mark.svg`](../assets/clusterforge-mark.svg) where a compact square mark is more appropriate, such as an avatar, favicon or small project card.

## Palette

| Role | Value |
|---|---|
| Background | `#0b1220` |
| Primary text | `#f8fafc` |
| Steel / node accent | `#94a3b8` |
| Secondary steel | `#64748b` |
| Forge orange | `#f97316` |
| Forge highlight | `#fb923c` |

## Usage

- keep sufficient clear space around the logo
- do not stretch or skew the mark
- preserve the dark/steel/orange visual relationship
- avoid adding glow, robot/brain imagery or unrelated AI symbolism
- prefer the vector SVG assets so the logo stays sharp at any size

The visual identity is intended to read as infrastructure engineering and orchestration first, with AI/compute support represented by the product rather than by generic AI branding.
