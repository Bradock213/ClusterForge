# ClusterForge Support

ClusterForge is an active solo-developed MVP. Public support is currently best-effort and focused on reproducible technical issues.

## Before opening an issue

Please check:

- the latest [release notes](https://github.com/Bradock213/ClusterForge/releases)
- [README.md](README.md)
- [Architecture](docs/ARCHITECTURE.md)
- [Roadmap](ROADMAP.md)
- [Security policy](SECURITY.md)

## Bug reports

Use the repository bug-report form and include:

- ClusterForge version or commit
- operating system and architecture
- component involved (controller, worker, watchdog, dashboard, installer)
- exact reproduction steps
- expected and actual behavior
- relevant logs with secrets removed

## Feature requests

Use the feature-request form and describe the problem first, then the proposed behavior and why it fits ClusterForge's orchestration scope.

## Security issues

Do **not** post credentials, tokens, pairing secrets or exploitable security details in a public issue. Follow [SECURITY.md](SECURITY.md).

## Current support level

MVP releases are intended for evaluation and development. They do not currently include a commercial SLA or guaranteed response time.
