# ClusterForge v0.1.0-mvp

First public MVP package for the native **ClusterForge Windows x86-64 worker and watchdog**.

> **Release channel:** MVP / pre-release  
> **Target platform:** Windows x86-64  
> **Production status:** Not production-ready yet

## What is included

- `ClusterForgeWorker.exe` — native Windows worker process
- `ClusterForgeWatchdog.exe` — worker/watchdog recovery helper
- `install-worker.ps1` — installation helper
- `uninstall-worker.ps1` — removal helper
- `TESTING.txt` — current testing guidance
- `SHA256.txt` — SHA-256 hashes for the packaged executables

## Verified release pipeline

This package is built by GitHub Actions from the repository build inputs. The release pipeline:

1. reconstructs the native Windows source used by the MVP build;
2. configures and compiles the x86-64 binaries;
3. runs worker and watchdog smoke tests;
4. generates SHA-256 checksums;
5. packages the tested output as `ClusterForge-Windows-Worker-x64.zip`;
6. publishes the package through GitHub Releases.

## Quick start

1. Download `ClusterForge-Windows-Worker-x64.zip` from the Assets section below.
2. Extract it on a Windows x86-64 machine you control.
3. Read `TESTING.txt`.
4. Review the PowerShell install script before running it.
5. Verify the hashes in `SHA256.txt` before testing the executables.

## What this release proves

The release provides a reproducible public build of the native Windows worker/watchdog component and validates the packaging and CI path used for future ClusterForge releases.

The wider ClusterForge project includes the controller/worker architecture, browser-based management direction, heterogeneous Windows/Linux nodes, resource-aware workload management, recovery logic and AI/compute orchestration foundations. Those areas are still being hardened and are not all distributed as a single production package in this release.

## Known limitations

- MVP/pre-release quality; interfaces and deployment procedures may change.
- Current public binary package focuses on the Windows worker/watchdog component.
- Full production hardening, container workloads and broader AI/compute orchestration remain in active development.
